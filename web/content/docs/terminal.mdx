title: The terminal
description: Yeet's terminal backend, shell environment, link handling, notifications, and safety features.

Every terminal pane runs your real login shell using a native, GPU-accelerated
Alacritty terminal backend. Yeet owns the surrounding behavior—pane focus,
search, notifications, links, history, themes, and paste safety.

## Your shell, unchanged

Each session starts your account's login shell, so your prompt, aliases,
functions, and dotfiles load as they do in any terminal. Yeet adds capability
and identity variables:

|| Variable | Value |
|| --- | --- |
|| `TERM_PROGRAM` | `Yeet` |
|| `TERM_PROGRAM_VERSION` | Yeet's marketing version |
|| `YEET_TERM` | `alacritty` |

`TERM_PROGRAM` is this app. Official Kero 0.1.24 set it to `ghostty` so
image-aware CLIs would take Ghostty's branch; Yeet has no Ghostty. The
Alacritty surface implements the Kitty graphics protocol (queryable via APC
`Gi`). `YEET_TERM` names the emulator. `TERM` stays `xterm-256color` and
`COLORTERM` stays `truecolor`.

<Callout type="info">
Yeet does not read an external Alacritty config. Fonts, colors, and input
behavior are configured in Yeet's own [settings](/docs/configuration).
</Callout>

## Search

|| Action | Shortcut |
|| --- | --- |
|| Find | <kbd>Cmd</kbd>+<kbd>F</kbd> |
|| Find next | <kbd>Cmd</kbd>+<kbd>G</kbd> |
|| Find previous | <kbd>Shift</kbd>+<kbd>Return</kbd> in the find bar |
|| Use selection for find | <kbd>Cmd</kbd>+<kbd>E</kbd> |
|| Clear the terminal | <kbd>Cmd</kbd>+<kbd>K</kbd> |

Find acts on the focused terminal or editor pane and remains active while its
search field owns keyboard focus.

## Paths and URLs

Yeet recognizes web URLs and existing local paths printed by terminal
programs. Local links can be absolute, `~/`-relative, `./` or `../` relative,
or relative to the pane's live working directory. A diagnostic suffix such as
`:42` or `:42:7` does not stop the underlying file from being found.

- **Command-click** a local path to reveal it in Finder, or a URL to open it in
  the default browser.
- **Command-right-click** a path for **New File Tab** / **New File Pane**, or a
  URL for **New Browser Tab** / **New Browser Pane**.

This gives compiler output and agent transcripts a direct route back into the
same project. Browser behavior is covered in [Browser panes](/docs/browser).

## Notifications

Yeet forwards two terminal events to Notification Center:

- a bell from a session that is not focused;
- an `OSC 777;notify` request from a program such as a long-running build or
  coding agent.

Notifications can play the system sound. Clicking one activates Yeet and jumps
to the exact session that emitted it. macOS asks for permission only when a
terminal first tries to notify you, not when Yeet launches.

## Progress reports

Programs that emit `OSC 9;4` progress get a slim bar above the terminal, with
distinct normal, paused, and error states. There is nothing to enable: if the
program reports progress, the pane shows it.

## Clipboard, drops, and paste safety

- **Clipboard reads are confirmed.** `OSC 52` can ask for the macOS clipboard,
  including from a remote host over SSH. Yeet asks before returning it.
- **Risky pastes are flagged.** Multi-line or command-like text is held behind
  a confirmation instead of being submitted immediately.
- **Files become shell-safe paths.** Finder-copied or dragged files are inserted
  as quoted absolute paths. Clipboard images still reach image-aware TUIs.

## Option-key input

By default, Option stays with the active macOS input source so layouts such as
Polish Pro can type composed characters. Enable **Use Option as Alt/Meta** in
Settings when a terminal program should receive Option-key chords as Meta
shortcuts instead. See
[`terminal.macos-option-as-alt`](/docs/configuration#terminalmacos-option-as-alt).

## The `yeet` command

Every Yeet terminal includes a project-aware CLI:

```sh
yeet                         # create a project at the current directory
yeet vim ~/src/app.swift     # create it and run this argv in the first terminal
yeet +themes                 # browse and preview themes interactively
yeet +themes --list --dark   # print theme names without the browser
yeet +help                   # show all command groups
```

The theme browser previews each selection across the whole app; Return saves
it and Escape restores the previous theme.

## Fonts

Yeet bundles JetBrains Mono plus Nerd Font symbols. Any installed monospace
family can replace it. See [`font-family`](/docs/configuration#font-family),
[`font-size`](/docs/configuration#font-size), and
[`terminal.font-thicken`](/docs/configuration#terminalfont-thicken).
