---
title: Yeet 是什么
description: 原生 macOS 终端工作区——项目、会话、浏览器、文件、git 与编码 agent，都在同一个窗口里。
---

Yeet 是一个终端。窗口里其余的部分，是为了让你不必离开它。

你手上的每个仓库，都会成为侧边栏里的一个**项目**。一个项目可以开任意多个终端**会话**，每个会话是一个标签页，有自己的工作目录和滚动历史；每个标签页还可以**分屏**成多个窗格。在这一切旁边是侧边面板，各自只需一个快捷键：用来审阅和提交的 git 面板、带编辑器的文件树，以及当前会话正在跑哪些进程、开了哪些端口的实时视图。

浏览器窗格和编码 agent 状态也在同一个项目布局里，不会再变成一堆要单独管理的窗口。

终端窗格使用原生 GPU 加速的 [Alacritty](/zh/docs/terminal) 后端。你的 shell、提示符、别名和 dotfiles 一律原封不动。

![Yeet 中打开了 git 面板的终端会话](/yeet-screenshot.png)

## 它不是什么

Yeet 不是 IDE，也不打算变成 IDE。git 和文件面板的存在，是为了让你不切换应用就能读一段
diff、改一个错字——而不是让你整天泡在里面。它也不会背着你做事：每一个 git 操作都对应一条你本可以自己敲的命令，输出会原样展示给你。

## 免费，而且很低调

Yeet 免费且开源（GPLv3），不需要账号，也没有订阅。应用和本站都不发送遥测数据，也不做分析统计。打包的 Yeet 没有 Sparkle 订阅源，也不会自己检查更新；请从源码构建，或在 GitHub Release 带有 Yeet.zip 时用 Homebrew / zip。浏览器和 agent CLI 只会发起你明确要求的请求。
