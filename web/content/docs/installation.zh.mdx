本仓库发布的是 **Yeet**，基于 [Kero](https://github.com/egoist/kero)（EGOIST）。构建是 **ad-hoc 签名**（没有 Apple Developer Program / Developer ID），不是 [kero.sh](https://kero.sh) 上经过公证的官方应用。当前代码需要 macOS 15.6（Sequoia）或更高。

如果你要的是 Yeet，**不要**运行 `brew install egoist/tap/kero`。那条命令会安装官方 Kero（`Kero.app` / `sh.kero`）。Yeet 安装的是 `Yeet.app` / `sh.yeet`，配置在 `~/.config/yeet`。目录不存在时会自动创建，不会导入旧 Kero 或 Kerox 配置。

## 从源码构建

这是得到本地应用的支持方式。你需要 **Xcode 26.5** 或更高版本，以及 [Rust 工具链](https://rustup.rs) 来构建 `Vendor/alacritty-bridge`。克隆远端、Debug 与 Release 的说明见 [CONTRIBUTING.md](https://github.com/ttaatoo/yeet/blob/main/CONTRIBUTING.md)。

```bash
git clone https://github.com/ttaatoo/yeet.git
cd yeet
xcodebuild -project yeet.xcodeproj -scheme yeet -configuration Debug -destination 'platform=macOS,arch=arm64' build
```

也可以打开 `yeet.xcodeproj`，运行 `yeet` scheme。

维护者打包的 ad-hoc `Yeet.app` + `Yeet.zip` 来自 `scripts/package.sh`。

## GitHub zip 与 Homebrew

仅当 [GitHub Release](https://github.com/ttaatoo/yeet/releases) 附带 `Yeet.zip` 时：

下载该 zip，解压后把 **Yeet** 拖进「应用程序」文件夹。

或使用仓库里的 cask（下载的是同一份 zip；每个版本都会钉死 `sha256`）：

```bash
brew tap ttaatoo/yeet https://github.com/ttaatoo/yeet
brew install --cask ttaatoo/yeet/yeet
```

升级：

```bash
git -C "$(brew --repo ttaatoo/yeet)" pull && brew upgrade --cask ttaatoo/yeet/yeet
```

第一次启动时，Gatekeeper 可能会拦截。cask 不会去掉隔离属性。到 **系统设置 → 隐私与安全性 → 仍要打开**。

用 formula 编译（`brew install --formula --HEAD ttaatoo/yeet/yeet`）同样需要 Xcode 26.5+ 和 Rust。更推荐上面的步骤；有 `Yeet.zip` 时再用 cask。

## 更新

Yeet 不包含应用内更新器。请从源码重新构建，或在 GitHub Release 带有 Yeet.zip 时使用 Homebrew 或 zip。

## 从 Finder 打开文件夹

Yeet 注册了一个名为 **New Yeet Project Here** 的 macOS 服务。在 Finder 里选中一个或多个文件夹，右键，从 **服务** 子菜单里选它——每个文件夹都会作为一个项目打开，终端已经在对应目录里启动好了。

如果菜单里没有它，去 **系统设置 → 键盘 → 键盘快捷键 → 服务 → 文件和文件夹** 打开。macOS
只会在应用至少启动过一次之后才列出新服务。

## 卸载

如果打开了 **设置 → Automation → AI**，请先关掉再删除应用，让 Yeet 移除它安装的 agent 支持。

如果是用 Homebrew 装的：

```bash
brew uninstall --cask ttaatoo/yeet/yeet
```

否则从「应用程序」里删掉 `Yeet.app`。如果想彻底清干净，再删掉它的配置：

```bash
rm -rf ~/.config/yeet
```

窗口布局、侧边栏宽度和会话快照存在 macOS 自己的偏好设置里：

```bash
defaults delete sh.yeet
```
