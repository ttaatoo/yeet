This repository ships **Yeet**, based on [Kero](https://github.com/egoist/kero) by EGOIST. Builds are **ad-hoc signed** (no Apple Developer Program / Developer ID). That is not the notarized app from [kero.sh](https://kero.sh). The current tree needs macOS 15.6 (Sequoia) or later.

Do **not** run `brew install egoist/tap/kero` if you want Yeet. That command installs official Kero (`Kero.app` / `sh.kero`). Yeet installs `Yeet.app` / `sh.yeet` and keeps settings in `~/.config/yeet`. Yeet creates this directory when needed and does not import older Kero or Kerox settings.

## Build from source

This is the supported way to get a local app. You need **Xcode 26.5** or later plus a [Rust toolchain](https://rustup.rs) for `Vendor/alacritty-bridge`. Full clone remotes and Debug vs Release notes are in [CONTRIBUTING.md](https://github.com/ttaatoo/yeet/blob/main/CONTRIBUTING.md).

```bash
git clone https://github.com/ttaatoo/yeet.git
cd yeet
xcodebuild -project yeet.xcodeproj -scheme yeet -configuration Debug -destination 'platform=macOS,arch=arm64' build
```

Or open `yeet.xcodeproj` and run the `yeet` scheme.

A maintainer-cut ad-hoc `Yeet.app` + `Yeet.zip` is `scripts/package.sh`.

## GitHub zip and Homebrew

Only when a [GitHub Release](https://github.com/ttaatoo/yeet/releases) includes `Yeet.zip`:

Grab that zip, unzip it, and drag **Yeet** into your Applications folder.

Or use the in-repo cask (it downloads the same zip; `sha256` is pinned per release):

```bash
brew tap ttaatoo/yeet https://github.com/ttaatoo/yeet
brew install --cask ttaatoo/yeet/yeet
```

Upgrade:

```bash
git -C "$(brew --repo ttaatoo/yeet)" pull && brew upgrade --cask ttaatoo/yeet/yeet
```

The first launch may be blocked by Gatekeeper. The cask does not strip quarantine. Use **System Settings → Privacy & Security → Open Anyway**.

Compiling with the formula (`brew install --formula --HEAD ttaatoo/yeet/yeet`) also needs Xcode 26.5+ and Rust. Prefer the steps above, or the cask when `Yeet.zip` exists.

## Updates

Yeet does not include an in-app updater. Rebuild from source, or use Homebrew
or a new GitHub Release zip when that asset exists.

## Open a folder from Finder

Yeet registers a macOS service called **New Yeet Project Here**. Select one or
more folders in Finder, right-click, and pick it from the **Services** submenu —
each folder opens as a project with its terminal already started there.

If it's missing from the menu, turn it on under **System Settings → Keyboard →
Keyboard Shortcuts → Services → Files and Folders**. macOS only lists a new
service after the app has been launched once.

## Uninstalling

If **Settings → Automation → AI** is enabled, turn it off before deleting the
app so Yeet can remove the agent support it installed.

If you installed with Homebrew:

```bash
brew uninstall --cask ttaatoo/yeet/yeet
```

Otherwise delete `Yeet.app` from Applications. Then remove its settings if you want a
clean slate:

```bash
rm -rf ~/.config/yeet
```

Window layout, sidebar widths, and the session snapshot live in macOS's own
preference store:

```bash
defaults delete sh.yeet
```
